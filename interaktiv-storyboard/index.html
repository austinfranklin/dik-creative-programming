Interaktiv Storyboard

Modifiera koden för att skapa din egen animerade berättelse

Klicka på spelytan ovan för att gå framåt i berättelsen!

1. Kom igång (Setup)

Följ dessa steg för att starta projektet på din dator:

  1. Ladda ned och packa upp projektmappen interaktiv-storyboard.
  2. Öppna mappen i Visual Studio Code (File > Open Folder).
  3. Installera tillägget Live Server av Ritwick Dey (klicka på byggkloss-ikonen i vänstermenyn, sök efter Live Server och klicka på Install).
  4. Starta den lokala servern genom att högerklicka på index.html och välja "Open with Live Server" (eller klicka på "Go Live" längst ned i fönstret). Projektet öppnas i din webbläsare!

Vad består projektet av?

• index.html: Bygger upp struktur och text på webbsidan.

• styles.css: Bestämmer utseende, färger och layout.

• sketch.js: Innehåller logik, animationer och berättelse.

• assets mappen: När all bilderna finns.

Obs: Du behöver bara redigera filen sketch.js i den här uppgiften!

2. Grundläggande syntax & tips

Viktiga sökvägar och kortkommandon:

• Sök i koden: Tryck Cmd + F (macOS) eller Ctrl + F (Windows) i VS Code för att snabbt söka efter text, t.ex. // STUDENT:.

• Spara & Ångra: Spara filen med Cmd + S / Ctrl + S. Ångra misstag med Cmd + Z / Ctrl + Z.

• Kommatecken (,): Alla värden i ett objekt (inuti {}) separeras med kommatecken. Glöm inte komma mellan element i listor!

• Semikolon (;): Avslutar enskilda kodrader och instruktioner.

• Skiftlägeskänslighet: JavaScript skiljer på stora och små bokstäver. imgName och imgname behandlas inte som samma sak.

• Kommentarer (//): Rader som börjar med // körs inte av datorn. De är till för att förklara koden.

3. Canvas & Koordinatsystem

Ritytan (Canvas) i projektet har storleken 800 × 600 pixlar (Bredd: 800px, Höjd: 600px).

Datorgrafik använder ett koordinatsystem där origo (x: 0, y: 0) ligger i det översta vänstra hörnet:

  • x = 0 är längst till vänster, x = 800 är längst till höger.
  • y = 0 är längst upp, y = 600 är längst ned.
  • Positionen (x: 400, y: 300) är exakt i mitten av skärmen.

4. Dina uppgifter

1. Lägg till egna bilder
Placera dina bildfiler i mappen assets/. Ändra bildnamnet i sketch.js till ditt eget filnamn (t.ex. en groda eller en cykel). Kom ihåg kommatecknet efter raden!
imgName: 'min_bild.jpg', // Kommatecken i slutet!
UTMANING (Frivillig): Hur justerar du bildens storlek så att bildförhållandet (aspect ratio) bevaras när den skalas upp eller ned? Använd koden nedan. Vad mer måste ändras i funktionen ritaElement() för att detta ska fungera?
let skala = min(w / img.width, h / img.height);
2. Skapa nya scener
Lägg till fler scener i listan scener. Kopiera mallen nedan och klistra in i koden. Glöm inte kommatecknet mellan scen-objekten!
{
  text: "Skriv din egen text här!",
  background: "#c084fc",
  elements: [
    { imgName: 'min_bild.jpg', startX: 100, startY: 300, endX: 400, endY: 300, width: 100, height: 100 }
  ]
},
UTMANING (Frivillig): Just nu varar alla scener exakt lika länge (SCEN_DURATION). Hur kan du ändra koden så att specifika scener stannar längre på skärmen än andra?
Tips: Överväg att lägga till en egenskap som duration inuti scen-objektet (t.ex. duration: 240) och läsa av det värdet inuti draw() istället för att använda en enda global konstant.
3. Animera rörelser
Ändra startX, startY, endX och endY för att flytta dina objekt över skärmen.
UTMANING (Frivillig): Hur kan du animera storleken på bilderna under scenens gång? Tänk på hur lerp() används i koden för positionen.
4. Easing
Om du vill ha en mjukare och mer naturlig rörelse i animationen kan du aktivera mjukgörning (easing). Ta bort kommentarstecknen (//) framför följande rad i draw():
t = t * t * (3 - 2 * t);
UTMANING (Frivillig): Vad representerar variabeln t i beräkningen, och hur påverkar matten i koden hastigheten i början och slutet av rörelsen?
5. Designa scenens stämning & komposition
Använd färger och placering för att förstärka berättelsens känsla och stämning. Testa att byta ut färgkoder (t.ex. "#1e1b11") mot egna färgpaletter som passar scenens ton (t.ex. varma varningstoner, kalla nattfärger eller lugna pasteller). Du kan gör denna websidan att välja färgen.
// Experimentera med färger och placering:
        background: "#0f172a", // Ändra HEX-koden för att skapa rätt stämning!
        elements: [
          // Tänk på komposition: Skapa balans genom bildernas placering och storlek
          { imgName: 'figur.png', startX: 100, startY: 450, endX: 400, endY: 200, width: 150, height: 150 }
        ]
UTMANING (Frivillig): Hur kan du använda visuell hierarki och "kontrast" för att dra blicken till den mest viktiga figuren i scenen?
Tips: Testa att göra huvudkaraktären större (t.ex. width: 150) än bakgrundskaraktärerna (t.ex. width: 70) eller låta den rörliga figuren korsa hela skärmen.

Exempelkod för en scen

{
  text: "Austin och Anders har kommit fram till skolan!",
  backgroundImageName: "skola.jpg",
  elements: [
    { imgName: "austin.jpg", startX: -100, startY: 450, endX: 250, endY: 450, width: 90, height: 90 },
    { imgName: "anders.jpg", startX: 900, startY: 450, endX: 350, endY: 450, width: 90, height: 90 }
  ]
}
