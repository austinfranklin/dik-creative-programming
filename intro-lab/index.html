Setup

Välkommen till labbmallen för interaktiv storyboard! Din uppgift är att modifiera filen sketch.js för att berätta din egen historia.

Hitta rätt fil: Öppna filen sketch.js i din texteditor (t.ex. VS Code). Leta efter kommentarer som börjar med // STUDENT:. Det är där du ska göra dina ändringar.

Hur fungerar koden?

Storyboarden är uppbyggd av en lista med scener. Varje scen är ett objekt i en array som innehåller text, bakgrund och en lista av element (bilder) som ska ritas ut. Varje scen kan ha en fast bakgrundsfärg (background: "#färgkod") eller en bakgrundsbild (backgroundImageKey: "bildnyckel"). Dessutom kan varje scen innehålla flera objekt samtidigt i sin elements-lista, vilket gör att du kan animera flera figurer på en gång!

Dina uppgifter

Lägg till dina egna bilder
Placera dina bildfiler i mappen assets/. Den preload() funktionen i sketch.js ska ladda dem automatiskt, men du måste växla namnet för värje scen du vill gör. You may use an image of a frog, bicycle, or anything else!

imgName: 'martin.jpg' // Växla namnet här!
QUESTION: How do you adjust image size? To keep the aspect ratio to same when scaling, use the code below. What else must be changed in order for this to work? HINT: in function ritaElement(...).

let skala = min(w / img.width, h / img.height);
Skapa nya scener
Lägg till fler scener i listan. Du kan bestämma text, om det ska vara bakgrundsfärg eller bakgrundsbild, samt vilka figurer som ska visas. Kopiera den här texten:
{
  text: "Skriva texten här!",
  //backgroundImageName: "skola.jpg", // Gör din filnamn!
  //background: "#c084fc" // Om du vill bara färg.
  elements: [
    // Lägg alla lärar-objekt som ska ritas ovanpå bakgrundsbilden:
    { imgName: 'austin.jpg', ... },
    { imgName: 'anders.jpg', ... },
    { imgName: 'mattias.png', ... },
    { imgName: 'martin.jpg', ... }
  ]
}
Syntax Help
Go over syntax! CMD+S, CMD+Z, etc.
Animera rörelser
Ställ in startX, startY, endX och endY för bilderna för att få dem att röra sig över skärmen.
{
  imgName: 'austin.jpg',
  startX: 180,
  startY: 300,
  endX: 180,
  endY: 300,
  width: 100,
  height: 100
}
QUESTION: How do you animate the size of the images? Consider lerp()
Easing
If you want smooth movements for scenes, uncomment the following line to add easing.

t = t * t * (3 - 2 * t);
QUESTION: What does 't' refer to, and how do you change the easing?

Exempelkod för en scen

Här är ett exempel på en scen som använder en bakgrundsbild (skola.jpg) och animerar två figurer samtidigt: 

{
  text: "Austin och Anders har kommit fram till skolan!",
  backgroundImageName: "skola.jpg", // Hela filnamnet för bakgrundsbilden
  elements: [
    {
      imgName: "austin.jpg", // Hela filnamnet för figurens bild
      startX: -100,          // Startar utanför skärmen till vänster
      startY: 450,
      endX: 250,             // Glider in till sin position
      endY: 450,
      width: 90,
      height: 90
    },
    {
      imgName: "anders.jpg", // Hela filnamnet för figurens bild
      startX: 900,          // Startar utanför skärmen till höger
      startY: 450,
      endX: 350,             // Glider in och ställer sig bredvid Austin
      endY: 450,
      width: 90,
      height: 90
    }
  ]
}
